# 베리타스 러닝센터 출결관리

학생 명단과 출결 기록을 관리하고, 보호자 문자 앱에서 출석 알림을 확인·전송하는 설치형 웹앱(PWA)입니다.

## 제공 기능
- 학생 이름과 보호자 휴대폰 번호 등록 및 학생 삭제
- 출석 시간 기록, 브라우저 기기의 `localStorage`에 자동 저장
- 기록별 선택 삭제, 여러 건 선택 삭제
- 출석 알림 문구를 보호자 번호와 함께 기본 문자 앱에 전달
- 오프라인 캐시 및 홈 화면 설치 지원

## 게시 및 설치
GitHub Pages에 게시해야 홈 화면 설치 기능과 서비스 워커가 동작합니다. 저장소의 **Settings → Pages**에서 배포 원본을 `Deploy from a branch`, 브랜치 `feature/attendance-sms`, 폴더 `/(root)`로 지정한 뒤 게시된 HTTPS 주소를 엽니다.

- **Android/Chrome:** 게시 주소를 열고 브라우저 메뉴의 **앱 설치** 또는 **홈 화면에 추가**를 누릅니다. 지원되는 경우 앱 화면의 **홈 화면 설치** 버튼도 표시됩니다.
- **iPhone/iPad/Safari:** 게시 주소를 Safari로 연 다음 **공유 → 홈 화면에 추가**를 선택합니다.

실제 기기에 설치하려면 이 저장소의 소유자 또는 권한이 있는 관리자가 GitHub Pages를 켜야 합니다. 이 저장소를 수정하는 것만으로는 사용자의 기기에 원격 설치할 수 없습니다.

## 문자 발송 안내
출석 등록 후 문자 앱의 새 메시지 화면을 열고 학생 이름, 출석 시각, 센터 이름이 들어간 안내문을 채웁니다. 사용자가 문자 앱에서 내용을 확인하고 **직접 전송**해야 하며, 웹앱이 몰래 또는 자동으로 문자를 발송하지 않습니다. 기기/기본 문자 앱에 따라 SMS 링크 처리 방식이 다를 수 있습니다.

보호자 전화번호 및 출결 기록은 현재 사용 중인 브라우저의 해당 기기에 저장되며 서버로 전송되거나 다른 기기와 동기화되지 않습니다. 브라우저 저장 데이터를 지우면 앱의 저장 내용도 사라질 수 있으므로 필요한 경우 별도로 백업하세요. 보호자 연락처 사용 및 문자 발송에 필요한 동의를 받으세요.
